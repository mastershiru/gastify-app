# Changelog

## [Unreleased]

### Added
- Floating Liquid Glass tab navigation for Home, Receipts, Notifications, and Profile.
- Manual expenses, All Expenses list, receipt-history deletion flows, and read-only receipt confirmation.
- Secure PIN/biometric app lock with a theme-aware unlock screen.
- Local scheduled monthly, yearly, and Philippine-holiday notifications with an on-device inbox and detail screen.

### Fixed
- Nested Home and Notifications screens now return to their owning tab.
- Profile Log out clearance above the floating tab dock.
